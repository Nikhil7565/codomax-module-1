# Day 2 - AI vs ML vs Deep Learning and Real-World Applications

## 1. Artificial Intelligence (AI)

Artificial Intelligence is the broader field of creating machines and software that can perform tasks that normally require human intelligence.

AI can involve:
- Reasoning
- Problem solving
- Understanding language
- Recognizing images
- Making decisions

## 2. Machine Learning (ML)

Machine Learning is a subset of AI where computers learn patterns from data and use those patterns to make predictions or decisions.

Basic ML process:

Data → Training → Model → Prediction

## 3. Deep Learning (DL)

Deep Learning is a subset of Machine Learning that uses artificial neural networks with multiple layers.

Deep Learning is especially useful for:
- Images
- Speech
- Text
- Video
- Complex pattern recognition

## 4. Difference Between AI, ML and Deep Learning

| AI | Machine Learning | Deep Learning |
|---|---|---|
| Broad field | Subset of AI | Subset of ML |
| Simulates intelligent behavior | Learns from data | Uses multi-layer neural networks |
| Can use rules or learning | Usually requires training data | Usually requires large amounts of data |
| Example: AI chatbot | Example: spam detection | Example: image recognition |

## 7. Key Takeaway

AI is the broad concept of machines performing intelligent tasks.

Machine Learning is a way of achieving AI by learning patterns from data.

Deep Learning is a specialized form of Machine Learning based on multi-layer neural networks.
